    <h1>Tic Tac Toe</h1>

    <p>
        A responsive Tic Tac Toe game built using HTML, CSS, and JavaScript.
    </p>

    <h2>Features</h2>

    <ul>
        <li>Two-player Tic Tac Toe game</li>
        <li>X and O turn indicator</li>
        <li>Automatic winner detection</li>
        <li>Draw detection</li>
        <li>Reset Game button</li>
        <li>New Game button</li>
        <li>Responsive design for mobile, tablet, and desktop</li>
        <li>Interactive game board</li>
    </ul>

    <h2>Technologies Used</h2>

    <ul>
        <li>HTML5</li>
        <li>CSS3</li>
        <li>JavaScript</li>
    </ul>

    <h2>How to Play</h2>

    <ol>
        <li>Player X starts the game.</li>
        <li>Click on any empty box to place your mark.</li>
        <li>The turn automatically switches between X and O.</li>
        <li>The first player to complete a row, column, or diagonal wins.</li>
        <li>If all 9 boxes are filled without a winner, the match is a draw.</li>
        <li>Use <strong>Reset Game</strong> or <strong>New Game</strong> to start again.</li>
    </ol>

    <h2>Winning Patterns</h2>

    <p>The game checks 8 possible winning combinations:</p>

    <ul>
        <li>3 Rows</li>
        <li>3 Columns</li>
        <li>Top-left to bottom-right diagonal</li>
        <li>Top-right to bottom-left diagonal</li>
    </ul>
